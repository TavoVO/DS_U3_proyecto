# PHP Shopping Cart Exercise

Academic web-development exercise for a simple shopping-cart flow.

## Contents

- PHP pages for catalog and cart interactions
- SQL script for the supporting database
- Image assets

## Technologies

PHP, HTML, SQL, and MySQL-compatible databases.

## Running locally

1. Create a local database using `php_tiendita_carrito.sql`.
2. Configure the PHP database connection if required.
3. Serve the project through a local PHP environment.
